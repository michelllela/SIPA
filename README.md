
# SIPA — Final Project Information System

SIPA (Sistem Informasi Proyek Akhir) is a web-based information system developed to support the management of Final Projects at Institut Teknologi Del.

The system aims to improve administrative efficiency, documentation, and communication between students, supervisors, and administrators throughout the Final Project process.

## Project Overview

The system provides a centralized platform for managing Final Project activities, replacing manual administrative processes with a more structured and integrated workflow.

## User Roles

### Student
- Manage Final Project title submissions
- Submit and manage supervision requests
- Upload and manage Final Project documents
- View supervision and document review status

### Supervisor
- Respond to Final Project title submissions
- Manage supervision requests
- Review submitted documents
- Provide feedback and revision notes

### Administrator
- Manage student data
- Manage lecturer data
- Manage study program data
- Manage administrator accounts
- Manage document categories
